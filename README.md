# 公园节令联名履约

本仓库保存该服务的领域资料与最小事件约定，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `src/validator.js`：校验事件信封（必填字段、事件与聚合词表、时间格式），词表与契约保持一致。
- `src/ledger.js`：把事件流折叠成履约当前状态。事件被接收后不原地改写，业务更正（取消、收窄、冻结、处置）一律以后继事件表达。
- `src/fulfillment.js`：履约命令层。每条命令先校验业务不变量再产出后继事件，校验失败不产生任何事件。
- `data/sample.json`：单条样例事件。
- `data/scenario.mid-autumn.json`：中秋联名联调用事件流（产能、授权、设计、配方、生产、装配、放行、配额、预售、取消、自提、结算）。
- `tests/`：契约一致性、业务不变量与联调事件流回放。

## 领域边界

当前资料围绕文化元素授权、设计版次、食品配方与过敏原、工厂批次、非食品部件、组合装配、渠道配额、预售保留、门店自提与快递、破损补寄、临期处置和合作方结算整理。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

## 领域不变量

- **放行门槛**：礼盒的全部食品批次、非食品部件齐备且可用，贴的是当前标签版次，才可放行。
- **双产能**：900克手工与标准礼盒各自计量产能，互不占压；手工批次不能装进标准规格。
- **配额与预售**：按渠道预留；迟到支付按到期处理，与取消一样只释放一次配额，重复操作是安全空操作；已履约部分持续占用配额。
- **检验异常**：按口味定位受影响的食品批次、组合与订单，不冻结无关的香囊、茶饮等部件；已放行流入市场的组合通过追溯召回，不原地冻结。
- **授权收窄**：只约束尚未生产的版次；收窄前已产已售的批次保留当时依据，可继续装配放行。
- **真实可售**：门店看到本渠道配额余量与全网已放行余量取小，而非全网虚数。
- **按履约清算**：合作方结算只计已履约且未结算的订单，取消与过期不计。
- **全程追溯**：任一订单可追到具体食品批次与文创部件，破损补寄沿用同一追溯；消费者可确认取货时间、口味与过敏原。
