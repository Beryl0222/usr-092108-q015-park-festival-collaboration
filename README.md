# 公园节令联名履约后端

多家公园把古建纹样、花丝香囊、节令茶饮和月饼组合成中秋联名。文创店、茶社、食品工厂与线上渠道各自掌握库存，热门礼盒预售超过产能时，既要防超卖，又要保证文物纹样版次、食品标签与祝福卡定制在换批中对得上。

本仓库是该服务的**事件溯源领域内核**（零运行时依赖）：聚合 + 业务不变量 + 只读投影，命令式 API，全部规则由 `node:test` 场景测试覆盖。

## 运行

```bash
npm test          # 24 个场景测试
npm run walkthrough   # 中文端到端演示
```

## 领域模型

事件只追加，不原地改写；业务更正产生后继事件。一个聚合一条流，一次业务操作可跨多条流**原子提交**，提交时事件流过对应 reducer 演算，任何不变量失败则整笔回滚。

| 聚合 | 职责 |
| --- | --- |
| `collaboration_design` / `cultural_license` | 联名、文化元素授权、设计版次审定与替代 |
| `food_recipe` | 配方版次、口味、过敏原；检验异常挂口味维度 |
| `production_capacity` | 产能按模式（`handmade_900g` / `standard`）×工厂×日期分账 |
| `label_catalog` | 食品标签版次批准/撤版，维护每个配方的当前标签 |
| `component_lot` | 食品批次与非食品部件（香囊、纹样件、祝福卡）统一批次模型 |
| `bundle_definition` / `bundle_batch` | 组合 BOM、装配、放行、冻结、临期处置、召回 |
| `channel_quota` | 门店/渠道配额铺货、预售保留、确认、释放 |
| `customer_order` | 预售→消费者确认→支付→自提/快递→破损补寄/召回善后 |
| `partner_settlement` | 合作方按实际履约订单清算 |

## 关键规则（均可在测试中找到对应场景）

1. **产能分账**：900 克手工产品与标准礼盒使用不同产能桶，互不挤占；生产时原子扣减，超限拒绝且不留痕。
2. **放行闸口**（`verifyRelease`）：一个礼盒只有 BOM 全部部件齐备、每件食品挂载**当前批准**标签、且未临期，才可放行；缺标签或缺部件都带具体问题清单拒绝。标签撤版后旧批次换装当前标签才能重新放行。
3. **真实可售**：门店/渠道看到的是本配额行上 `已铺货可售 − 预售保留/已确认`，不是全网汇总虚数。预售超过可售直接拒绝。
4. **配额安全释放**：保留有过期时刻；迟到支付被明确拒绝并释放配额，取消订单（含已支付退款）同样安全释放，释放出的额度立即可再售。
5. **精确冻结**：某口味检验异常 → 该口味食品批次 → 含它的组合批次 → 对应铺货 → 未履约订单，逐层精确命中；不含该批次的香囊、茶饮、其他口味与其他渠道一律不动。
6. **授权收窄不溯及既往**：非食品部件入库时固化 `license_basis` 授权快照；收窄只拒绝此后的新生产与新版次审定，已售批次保留当时依据。
7. **消费者确认**：自提前必须确认取货时间、口味与过敏原；口味必须属于该组合，否则拒绝。
8. **全链路谱系**：口味↔食品批次↔组合批次↔订单双向可追；任一订单都可追到具体食品批次（口味/过敏原/标签/保质期）与文创部件（设计版次/授权快照）；补寄链路同样入谱系，召回可触达已签收订单。
9. **按实际履约清算**：只有自提完成或快递（含补寄）签收的订单进入合作方清算；已发货未签收、已取消、破损未补完都不计入；同一订单不重复清算。
10. **临期处置**：食品批次报废，含该批次的组合批次同步处置；无关组合不受影响。

## 目录

- `contracts/domain.schema.json`：全部事件类型、聚合类型与事件信封字段。
- `src/eventCatalog.js`：事件 ↔ 聚合唯一对照表。
- `src/validator.js`：事件信封校验（类型对照、时间格式、版本）。
- `src/domain/`：各聚合 reducer 与纯函数不变量（业务规则的唯一权威实现）。
- `src/app/eventStore.js`：多流原子提交、乐观并发（`expectedVersion`）、提交时 reducer 演算。
- `src/app/repository.js`：事件回放为聚合状态。
- `src/app/fulfillmentApp.js`：命令编排（应用服务）。
- `src/app/projections.js`：真实可售、谱系追溯、临期视图。
- `tests/helpers/fixture.js`：中秋联名世界夹具（古建纹样授权、香囊、茶饮、两种口味月饼、祝福卡、两门店一线上）。
- `tests/`：契约、产能、放行闸口、配额/订单、授权、谱系/召回、临期、结算、并发测试。
- `scripts/walkthrough.mjs`：可运行的中文端到端演示。

## 设计约定

- 事件一旦接收，其标识、发生时间与版本不被原地改写；更正以后继事件表达。
- 命令在提交前回放并校验，提交时 reducer 再次演算，双保险且规则只有一处实现。
- 涉及个人或商业敏感信息时，调用方只读取完成职责所必需的字段（订单只保留履约所需的选择与确认记录）。
